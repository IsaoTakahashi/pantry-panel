# ユーザーシナリオ一覧

現状の実装済み機能と Wishlist の未実装機能のユーザーシナリオをまとめる。
テスト設計・不足テスト洗い出しの参照資料として使用する。

各シナリオの**フェーズ**は `features.md` の実装フェーズに対応する。

---

## 実装済み機能

### A. 商品一覧表示

| ID | シナリオ |
|----|---------|
| A-1 | アプリを開くと、登録済みの商品が更新日時の降順（最近更新したものが先頭）で表示される |
| A-2 | 商品がゼロ件の場合、一覧は空で表示される（エラーにならない） |
| A-3 | ページ表示中にサーバーエラーが発生した場合、エラーメッセージが表示される |

---

### B. 商品登録（手動）

| ID | シナリオ |
|----|---------|
| B-1 | 「商品を追加」ボタンを押すと商品作成モーダルが開く |
| B-2 | 商品名とカテゴリを入力して登録すると、一覧の先頭に新しい商品が追加される |
| B-3 | 既に登録済みの商品名を入力すると「その商品は登録済みです」と表示され、登録ボタンが無効になる |
| B-4 | 検索テキストが入力済みの状態で「商品を追加」を押すと、その文字列が商品名の初期値にセットされる |
| B-5 | カテゴリフィルタが選択された状態で「商品を追加」を押すと、そのカテゴリが初期値にセットされる |
| B-6 | 買い物リストフィルタが ON の状態で作成すると、`wantToBuy=true` の状態で登録される |

---

### C. 商品削除

| ID | シナリオ |
|----|---------|
| C-1 | `wantToBuy=false` の商品には削除ボタンが表示され、押すと削除確認ダイアログが出る |
| C-2 | 削除確認ダイアログで「はい」を選ぶと、商品が一覧から消える |
| C-3 | `wantToBuy=true` の商品には削除ボタンが無効（または非表示）になる |

---

### D. 商品情報編集

| ID | シナリオ |
|----|---------|
| D-1 | 商品名をクリックすると商品名変更モーダルが開き、変更を保存すると即座に反映される |
| D-2 | カテゴリバッジをクリックするとカテゴリ変更モーダルが開き、変更を保存すると即座に反映される |
| D-3 | 編集後は一覧の並び順が変わらない（ソートキーが更新されない） |

---

### E. 買い物リスト（wantToBuy トグル）

| ID | シナリオ |
|----|---------|
| E-1 | カートアイコンをクリックすると `wantToBuy` が ON になり、商品が一覧の先頭に移動する |
| E-2 | `wantToBuy=true` の商品のカートアイコンを再クリックすると OFF になるが、一覧の順番は変わらない |
| E-3 | `wantToBuy=true` になった商品には視覚的な強調表示（アイコン色など）が付く |

---

### F. フィルタリング

| ID | シナリオ |
|----|---------|
| F-1 | 検索ボックスに文字を入力すると、商品名に部分一致する商品だけが表示される |
| F-2 | 検索ボックスの「クリア」ボタンを押すと、フィルタが解除されて全商品が表示される |
| F-3 | 買い物リストフィルタを ON にすると、`wantToBuy=true` の商品だけが表示される |
| F-4 | カテゴリドロップダウンで特定カテゴリを選ぶと、そのカテゴリの商品だけが表示される |
| F-5 | 複数のフィルタを同時に適用すると、すべての条件を満たす商品だけが表示される（AND 条件） |
| F-6 | フィルタが適用された状態でも「商品を追加」は使える |

---

### G. リアルタイム同期

| ID | シナリオ |
|----|---------|
| G-1 | 家族の別端末でアイテムが追加されると、ページを再読み込みしなくても自動的に一覧に表示される |
| G-2 | 別端末で `wantToBuy` をトグルすると、自分の画面にも反映される |
| G-3 | 別端末で商品を削除すると、自分の画面からも消える |
| G-4 | Supabase の環境変数が未設定の場合、コンソールに警告が 1 回出るが REST CRUD は正常動作する |

---

### H. シンプルビュー

| ID | シナリオ |
|----|---------|
| H-1 | ヘッダーの「Simple」スイッチを ON にすると、商品がコンパクトな 1 行表示に切り替わる |
| H-2 | シンプルビューでも商品名・カテゴリ・画像サムネイル・カートアイコンが確認できる |
| H-3 | スイッチを OFF に戻すと通常カードビューに戻る |

---

### I. 商品画像設定

| ID | シナリオ |
|----|---------|
| I-1 | 商品カードの画像エリアをクリックすると画像選択モーダルが開く |
| I-2 | モーダルを開くと商品名で自動的に Google 画像検索が実行され、候補が表示される |
| I-3 | 候補画像をクリックすると商品に画像が設定され、カードにサムネイルが表示される |
| I-4 | 検索ボックスのキーワードを変えて再検索できる |
| I-5 | 設定済み画像を「解除」すると、商品画像が削除されてデフォルト表示に戻る |
| I-6 | Google CSE が未設定（環境変数なし）の場合、画像検索モーダルにエラーメッセージが表示される |

---

### J. URL から商品登録（Phase 5 / 5.5）

#### J-1. 基本フロー

| ID | シナリオ |
|----|---------|
| J-1-1 | ヘッダーのリンクアイコンを押すと URL 入力モーダルが開く |
| J-1-2 | 商品ページの URL を入力して「取得」を押すと、商品名・画像が抽出されて商品作成モーダルが自動入力された状態で開く |
| J-1-3 | 自動入力された内容を確認・編集して「登録」を押すと商品が作成される |
| J-1-4 | 登録した商品には `sourceUrl` が保存され、ItemCard に外部リンクアイコンが表示される |
| J-1-5 | `ANTHROPIC_API_KEY` が未設定の場合、AI フォールバックはスキップされるが og:title / og:image による抽出は正常動作する |

#### J-2. エラー・エッジケース

| ID | シナリオ |
|----|---------|
| J-2-1 | URL が取得できない（404・タイムアウト等）場合、エラーメッセージが表示される |
| J-2-2 | エラー時に「詳細を表示」を展開すると、技術的な失敗情報（HTTP ステータス等）を確認できる |
| J-2-3 | 商品名が抽出できなかった場合は、名前を手入力して登録できる |

#### J-3. 抽出進捗表示（SSE）

| ID | シナリオ |
|----|---------|
| J-3-1 | URL を入力して「取得」を押すと、処理の進捗ステップ（fetching / extracting 等）がリスト表示される |
| J-3-2 | 完了済みのステップ・進行中のステップ・未着手のステップが視覚的に区別される |
| J-3-3 | 抽出が完了すると進捗リストが消えて通常の結果表示に切り替わる |

---

### K. Google 認証（Phase 6）

| ID | シナリオ |
|----|---------|
| K-1 | 未ログイン状態でアプリを開くとログイン画面が表示され、商品一覧にはアクセスできない |
| K-2 | 「Google でログイン」ボタンを押すと Google OAuth フローが始まり、認証後にアプリが使える状態になる |
| K-3 | ログイン済みの状態でアプリを開くと認証チェック後に商品一覧が表示される |
| K-4 | ヘッダーのアカウントメニューから「ログアウト」を押すと、セッションが終了してログイン画面に戻る |
| K-5 | `SUPABASE_JWKS_URL` が未設定の場合、JWT 検証をスキップして後方互換で動作する |

---

### L. グループ管理（Phase 6）

| ID | シナリオ |
|----|---------|
| L-1 | 初回ログイン後、グループを新規作成すると、自分がそのグループのオーナーになる |
| L-2 | グループメンバーを招待するためのリンク（invitation URL）を発行できる |
| L-3 | 招待リンクを踏んだユーザーがログインすると、グループに追加される |
| L-4 | 複数のグループに所属している場合、グループを切り替えると表示される商品一覧が切り替わる |
| L-5 | グループ名を変更できる |
| L-6 | 他のグループのデータは RLS により参照・変更できない |

---

## 未実装機能（Wishlist）

実装は未定。参考として主要なシナリオを記載する。

### M. 長い商品名の候補選択 UI

| ID | シナリオ |
|----|---------|
| M-1 | URL 抽出で商品名が 25 文字以上の場合、AI が生成した 3 つの短縮候補が表示される |
| M-2 | 候補 3 件＋元の名前から 1 つを選ぶと、商品作成モーダルにその名前がセットされる |

### N. レシピからの材料一括登録

| ID | シナリオ |
|----|---------|
| N-1 | レシピ URL を入力すると、材料一覧（調味料を除く食材）が AI で抽出されて表示される |
| N-2 | 一覧を確認・選択して「登録」を押すと、複数の商品が一括で作成される |

### O. 更新履歴（買った履歴）

| ID | シナリオ |
|----|---------|
| O-1 | `wantToBuy` を OFF にするとき「買った（履歴記録）」か「取消し（記録なし）」を選べる |
| O-2 | 商品の「最後に買った日」を確認できる |

### P. ToDo リスト

| ID | シナリオ |
|----|---------|
| P-1 | 買い物リストとは別タブで ToDo を追加・完了・削除できる |
| P-2 | ToDo に「行くお店」などのメモを紐付けられる |
