## Context

現行の商品一覧画面（`stock-items/page.tsx`）は、ヘッダー `py-4 px-6`・メイン `py-6`・グリッド `gap-4`・`ItemCard` `p-4` という余白設定を持つ。詳細な設計探索は `docs/superpowers/specs/2026-05-17-reduce-spacing-design.md` を参照。

## Goals / Non-Goals

**Goals:**
- Tailwind クラスの調整のみで一画面に表示できる商品数を増やす
- モバイル（1列表示）での体験を改善する

**Non-Goals:**
- モバイルでの列数変更（1列を維持）
- 画像サイズの変更（通常モード 64×64 px を維持）
- `ItemCardSimple` のカード内余白変更（すでに十分コンパクト）
- ロジック・動作の変更

## Decisions

**控えめな削減を選択**  
積極的に詰めすぎるとボタンのタッチ領域が小さくなる懸念がある。各変更を1段階（1 Tailwind ステップ）に留め、操作性を維持する。

| 対象 | 変更前 | 変更後 |
|------|--------|--------|
| ヘッダー | `py-4 px-6` | `py-2 px-4` |
| `<main>` | `py-6` | `py-4` |
| フィルター下マージン | `mb-6` | `mb-4` |
| グリッド gap | `gap-4` | `gap-3` |
| `ItemCard` padding | `p-4` | `px-3 py-2` |
| `ItemCard` gap | `gap-4` | `gap-3` |

**ボタン padding は変更しない**  
カートボタン・削除ボタン自体の `px-3 py-1.5` はそのまま維持し、タッチターゲットサイズを確保する。

## Risks / Trade-offs

- [商品名2行折り返し時の窮屈感] → `flex items-center` が維持されるため画像・ボタンの垂直位置は変わらない。許容範囲内。
- [ui-style-guide との乖離] → ページレイアウト要件が更新されるが、既存の視覚階層（カテゴリバッジ・影・ホバー）は維持するため影響は最小限。
