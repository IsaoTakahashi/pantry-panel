# 余白削減設計ドキュメント

## 背景

旧仕様（https://pantry-panel.web.app/）と比べて、特にモバイルサイズでの表示時に余白が大きく、一度に表示できる商品数が少ない。Tailwind クラスの調整のみで余白を削減し、可視件数を増やす。

## 決定事項

| 設問 | 決定 |
|------|------|
| 変更スコープ | ページ全体（ヘッダー・メイン・グリッド・カード） |
| モバイル列数 | 変更なし（1列のまま） |
| 通常モード画像サイズ | 変更なし（64×64 px のまま） |
| 削減レベル | 控えめ（B案） |

## 変更内容

変更対象は3ファイル。ロジック変更なし、Tailwind クラスの調整のみ。

### `frontend/src/app/stock-items/page.tsx`

| 場所 | 現状 | 変更後 |
|------|------|--------|
| ヘッダー | `py-4 px-6` | `py-2 px-4` |
| `<main>` | `py-6` | `py-4` |
| フィルター＋ボタン領域 | `mb-6` | `mb-4` |
| グリッド gap | `gap-4` | `gap-3` |

### `frontend/src/components/ItemCard.tsx`

| 場所 | 現状 | 変更後 |
|------|------|--------|
| `<article>` padding | `p-4` | `px-3 py-2` |
| `<article>` gap | `gap-4` | `gap-3` |

### `frontend/src/components/ItemCardSimple.tsx`

変更なし。すでに `px-4 py-2 gap-3` でコンパクト。ページレベル変更（グリッド gap・ヘッダー・メイン）の恩恵は受ける。

## エッジケース

| ケース | 結論 |
|--------|------|
| 商品名が長く2行折り返し | `flex items-center` 維持で問題なし |
| ボタンのタッチ領域 | ボタン自体の padding は変更しないため影響なし |
| ItemCardSimple との整合性 | 画像サイズ差（64px vs 32px）が引き続き差別化する |
| スナップショットテスト | 本プロジェクトに存在しないため問題なし |

## テスト方針

既存テスト（`ItemCard.test.tsx` / `ItemCardSimple.test.tsx` / `stock-items/page.test.tsx`）はロジック・aria 属性・クリックハンドラーを検証しており、Tailwind クラスを直接テストしていない。スタイル変更のみのため既存テストはそのまま通過する。追加テストは不要。視覚的確認（ローカル dev server）で代替する。
